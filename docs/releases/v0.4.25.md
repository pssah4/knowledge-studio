# Knowledge Studio 0.4.25

Prepared on private dev; not yet publicly released.

- Technical documentation containing symbolic home paths such as
  `~/.claude/settings.json` can synchronize with its existing history. Concrete
  device paths, device-binding fields and credentials remain protected.
- Clearance errors describe the paused sync and the required fresh retry. Local
  reviews of available working-copy notes remain separate from synchronization.
- Maintain instructions require a current status for every requested connection
  and report incomplete maintenance whenever reviews or synchronization remain open.
- This version also includes scoped Node source monitoring and compact archive
  triage from the previous private development build.

Install both skills for your platform. Maintain updates the project editor through
the existing version check; reload or reopen an already running editor afterward.
