# Knowledge Studio 0.4.27

Ingestion uses a focused guide and compact workflow responses to reduce repeated
instruction and review text in the agent conversation. Routine status and completion
checks retain their decisions, sources and blockers. Full review records remain
available through a content-bound detail request; older callers still receive the
full response by default.

The guide preserves complete source reading, visual-gap review, evidence and
completion checks. It clarifies that host supplements add missing content to the
extracted text. A completed, current graph does not need another refresh before an
unchanged follow-up step.

The editor also keeps the workspace busy until host folder initialization finishes.
Creating a note immediately after granting access no longer races with folder
binding.

Install both skills for the same platform and version, then refresh the project
editor. This release reduces conversation payloads; actual model charges depend on
the host session and have not been measured by these runtime checks.
