# Knowledge Studio v0.4.23

Knowledge Studio combines two AI skills with a local Markdown workspace:
`maintain-llm-wiki` curates sources and notes, and `query-llm-wiki` answers questions
with traceable evidence across connected wikis.

This release establishes the Knowledge Studio open-source repository and its
automated release distribution. Skill identities and existing wiki formats remain
compatible.

## Install

Choose one platform and install both matching `.skill` assets:

- Claude Code: `claude-code-maintain-llm-wiki.skill` and `claude-code-query-llm-wiki.skill`.
- Claude Cowork: `claude-cowork-maintain-llm-wiki.skill` and `claude-cowork-query-llm-wiki.skill`.
- Codex: extract the two `codex-*.skill` archives into your skills directory.
- ChatGPT: use the two `chatgpt-*.skill` assets in a workspace that supports skills and Node execution.
- Vault Operator: import both `vault-operator-*.skill` assets through its skill manager.

The `llm-wiki-0.4.23.zip` archive provides the combined Claude Code plugin.
Each download has a SHA-256 checksum. The release manifest preserves the platform
matrix; individual GitHub assets prefix the original skill filename with its platform.

See the [installation guide](../../README.md#skills-installieren) for host requirements.
